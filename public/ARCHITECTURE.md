# Dribble

A college basketball dynasty. You take a job, set the minutes, recruit, and coach the games.

The save stays on this device. It works offline. There is no account required to play.

The game is free. No ads, no energy gates, no loot boxes. An optional tip lives in Settings.

Selection Day, the résumé, and the bracket use the same field. If your school is in, you see the seed and the region. If it is out, the page says so.
